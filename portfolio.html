      How this site is built

      • Charts: Apache ECharts 5 (SVG rendering, a text description of every chart for screen readers), themed with the World Bank brand tokens.
      • Maps: the World Bank webmap standard I built: MapLibre GL JS and d3, Equal Earth projection, World Bank boundaries and disputed-area rules, and the standard’s automated checks (the reach map above passes all 119).
      • Front end: plain HTML, CSS and JavaScript with no build step; responsive from 360 to 1440 px; live embeds load one at a time.
      • Data: the content lives in small data files (data.js, print-maps.js), so adding a map is one line; thumbnails and print images are generated from the source PDFs.
      • Self-contained: fonts and libraries are bundled, so it runs on an internal server with no outside calls except the embedded maps themselves.
